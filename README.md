## Project

NetMessenger is a TCP/IP based multi-client chat and file-sharing application written in C.

## Main Features

- Multi-client communication using pthreads
- User registration and presence
- Broadcast messaging
- Private messaging
- Chat rooms
- File sharing
- Graceful client disconnect
- Server event logging
